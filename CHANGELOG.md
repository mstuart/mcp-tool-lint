# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-11

### Added

- Initial MCP tool definition linter with CLI and programmatic API.
- Built-in quality rules for descriptions, parameter descriptions, required arrays, action verbs, vague verbs, and duplicate names.
- Stable `--json` CLI output for automation.
- CLI stdin support via `-`.
- npm package metadata, MIT license, CI, release workflow, and standalone example.
